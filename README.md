# Data Modeling & Data Visualization with Alayta Bank

A complete data engineering mini-project focused on **data normalization**, **PostgreSql database design**, and **data visualization** using a simple banking dataset.



##  Project Overview

This project demonstrates a full mini data pipeline:

-  Data normalization applied to the **Alayta Bank dataset**
-  Database design and implementation using **PostgreSQL**
-  Data visualization using **Matplotlib**



##  Technologies Used

- 🐘 PostgreSQL — Relational database system
- 📊 Matplotlib — Data visualization
- 🧮 Pandas DataFrame — Data manipulation
